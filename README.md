# Tebo-View 4.0 合并破解版（私人存档）

把手上的三个 Tebo-View 版本合并成一套，去掉两道限制：

| 原限制 | 现象 | 处理 |
|---|---|---|
| 客户 ID 授权 | `没有权限打开该[客户ID：xxx]文件！` | 跳过授权比较，任何客户的 `.tvw` 都开 |
| `.tvw` 文件密码 | 弹密码框 / `密码不正确！` | 跳过密码框，直接读取 |

三个版本的程序本体其实是同一个 `Tebo-IctView.exe`，真正的差别只在 `IctViewLicense.dll`（各自写死一个授权客户）。所以合并 = 用最新的模块集（2015 版）+ 打 6 个字节的补丁。

## 包内容

`TeboView_Merged_4.0.zip`（解压即用）

```

├─ Tebo-IctView.exe.orig   未修改的原程序（回滚用）
├─ *.dll                   2015 版模块集，必须与 exe 同目录

├─ 破解报告.md             逆向过程、补丁地址、TVW 格式、验证数据

├─ patch_manifest.json     补丁清单 + 源/目标 SHA256
├─ 截图\                   打开时默认视图 / 全屏显示后 / H转接板层列表
└─ 使用说明.txt
```

## 补丁（只改 6 字节）

| 文件偏移 | 原始 | 改为 | 作用 |
|---|---|---|---|
| `0x001c7f` | `75 12` | `EB 12` | 文件版本比程序新时不再中断 |
| `0x001d1f` | `74 77` | `EB 77` | 跳过 `[客户ID]` 授权比较 |
| `0x001dd0` | `0F 84 A7 00 00 00` | `E9 A8 00 00 00 90` | 跳过 `.tvw` 密码框（jmp `0x401e7d`） |

第 3 处注意：6 字节 `je` 换成 5 字节 `E9` 后位移要按新指令结尾重算，`A7 → A8`，照抄会跳到指令中间直接崩。

## 用法

1. 解压，保持目录完整（DLL 缺一个都起不来）。
2. 双击 `Tebo-IctView.exe` → 文件 → 打开。
3. 画布是深蓝空白属正常（沿用了上次的视图缩放）：在「层」列表里勾上要看的层，再按 **Shift+Home**（= 全屏显示 / Zoom all）。

## 验证结论

- 49 个真实 `.tvw`（Gigabyte RTX 50 系、LCFC/Lenovo、H 转接板、Foxconn 等）：**47 个直接打开、零弹窗**；带密码的 20 个 Landrex 文件不再询问密码。
- 与正版授权路径对比：同一文件、同一次运行，截图像素级一致。
- 内存与渲染双重确认：文件尾部的网络名在进程内存里全部命中，`全屏显示` 后整板正常渲染。
- 2 个打不开的（`PG503-A02.tvw`、`LENOVO IdeaPad … NM-E541.tvw`）是更晚的 5.x 格式，与授权/密码无关，详见报告第 6 节。
